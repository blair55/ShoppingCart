# Shopping Cart Exercise

Time to complete ⏱️ approx 120 mins

Checkpoints 1 & 2 are available as commits and as branches

## Setup Choices

* Install [dotnet](https://dotnet.microsoft.com/en-us/download) locally

OR

* Open with an IDE/tool that supports [dev containers](https://containers.dev/supporting)

OR

- Launch an instant dev environment:

  [![Open in Dev Containers](https://img.shields.io/static/v1?label=Dev%20Containers&message=Open%20in%20%20vscode&color=blue)](https://vscode.dev/redirect?url=vscode://ms-vscode-remote.remote-containers/cloneInVolume?url=https://github.com/blair55/ShoppingCart)

  [![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/blair55/ShoppingCart)

## Run Tests

In the root folder

```bash
$ dotnet run --project ShoppingCart.Tests
```
## Watch Sample Client

In the root folder

```bash
$ dotnet watch --project ShoppingCart.Client
```
